# Productivity App

A modern, high-performance productivity application designed to help you focus and manage your daily tasks effectively.

## Features

- **Dashboard**: Real-time overview of your productivity.
- **Tasks**: Advanced task management system.
- **Journal**: Track your thoughts and progress.
- **Focus Mode**: Distraction-free environment with ambient sounds.

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Tech Stack

- React
- Typescript
- Vite
- Vanilla CSS
